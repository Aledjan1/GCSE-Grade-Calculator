# 🎓 GCSE Grade Calculator

A responsive GCSE Grade Calculator built using **HTML, CSS, and JavaScript**. Users can enter marks for multiple subjects, calculate percentages, and view estimated GCSE grades.

This project was created to practise JavaScript fundamentals, DOM manipulation, form validation, loops, and calculations.

## 🚀 Features

- Select subjects from a dropdown menu.
- Add multiple subjects dynamically.
- Enter achieved marks and maximum possible marks.
- Calculate percentages for individual subjects.
- Convert percentages into estimated GCSE grades (U–9).
- Calculate the average percentage across subjects.
- Display an estimated average GCSE grade.
- Validate user input and display error messages.
- Highlight invalid input fields.
- Responsive layout for desktop and mobile devices.

## 🛠️ Technologies Used

- **HTML5** — Page structure and form elements.
- **CSS3** — Styling, layout, and responsive design.
- **JavaScript (ES6)** — DOM manipulation, event handling, validation, and calculations.

## 💻 How to Use

1. Open `index.html` in your browser.
2. Select a subject.
3. Enter your marks and the maximum possible marks.
4. Click **Add Subject** to include additional subjects.
5. Click **Calculate Results**.
6. View your percentages, estimated grades, and average results.
