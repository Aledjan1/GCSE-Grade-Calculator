# GCSE Grade Calculator 🎓

A responsive GCSE Grade Calculator built with HTML, CSS and JavaScript.

Users can enter marks for multiple subjects, calculate percentages, and view estimated GCSE grades using a simplified practice grading scale.

## Features

- Select subjects from a dropdown list
- Add multiple subjects dynamically
- Enter marks and maximum possible marks
- Calculate percentages for individual subjects
- Convert percentages into estimated GCSE grades (U–9)
- Display average percentage and average grade
- Visualise the overall result with a circular progress indicator
- Validate user input and display error messages
- Automatically reset previous results when input values change
- Responsive layout for desktop and mobile devices

## Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla JS)

## How to Use

1. Select a subject.
2. Enter the marks achieved and maximum possible marks.
3. Click **Add Subject** to include additional subjects.
4. Click **Calculate Results**.
5. View individual results and the overall summary.
6. If you change any input, previous results are cleared until you calculate again.

## Important Note

This calculator uses a simplified grading scale for JavaScript practice. Official GCSE grade boundaries vary depending on the examination board, subject and year.
